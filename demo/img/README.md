# Local photos (optional)

Drop JPG files here to replace the hotlinked stock photos. A local file always wins;
if it is missing the page falls back to Unsplash, then Pexels.

Use this for photos from **Pixabay** or **Freepik** (their licences do not allow
hotlinking, so they must be downloaded and served from this folder), or for real
partner photography.

| File name | Where it appears |
|---|---|
| `hero.jpg` | Sales page hero |
| `stay.jpg`, `dine.jpg`, `restore.jpg` | "Stay / Dine / Restore" pillars |
| `room.jpg` | Waiting-list confirmation pop-up |
| `partner.jpg` | "Become a sumnight house" section |
| `mcp.jpg`, `kalm.jpg`, `tam.jpg` | Hotels: Maison Chao Phraya, Kalm Villas, Tamarind Hill |
| `nara.jpg`, `jardin.jpg`, `tide.jpg` | Restaurants: Nara Omakase, Jardin de Nuit, Charcoal & Tide |
| `still.jpg`, `lune.jpg` | Spas: Still Spa, Lune Wellness |

Recommended: landscape or portrait around 1600 px on the long side, under 400 KB.
Freepik free-licence images require an attribution line (e.g. in the footer).
